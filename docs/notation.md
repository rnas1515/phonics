# Coding notation (from the school's own reference pages)

Source: photos of the school's Coding Reminders, Syllable Division Procedure, Vowel Rules and phonics chart pages.
This file records the conventions only. It does not copy the pages.

| Mark | Used for | App tool |
|---|---|---|
| breve over a vowel | short vowel (vowel followed by a consonant) | `breve` |
| macron over a vowel | long vowel; open accented vowel; vowel before a silent e | `macron` |
| slash through a letter | silent letter: final e in V-C-e; the second vowel in a vowel team; kn, gn, wr | `strike` |
| straight underline | digraphs, trigraphs, quadrigraphs | `underline` |
| arc under letters | combinations (er, ir, ur, ar, or) and diphthongs (oi, oy, ou, ow) | `arc` |
| bracket in front of a syllable | final, stable syllables (ble, dle, fle, gle, ple, tle, tion, sion, ture ...), with the silent e crossed out | `bracket` |
| box | suffixes and prefixes | `box` |
| k-back | hard c (says /k/) | `kback` |
| cedilla | soft c (says /s/) | `cedilla` |
| schwa | unstressed vowel that says "uh" | `schwa` (tool exists; no lesson yet) |
| voice line | voiced letters (such as the th in "this", the s in "has") | `voice` (tool exists; no lesson yet) |
| vertical line between letters, V/C labels, accent mark | syllable division | `divide` (accent mark not built) |

Vowel teams ee, ai, ay and oa are shown with a macron on the first vowel, a slash through the second vowel,
and an underline under both. The app accepts either that full pattern or underline-only (`"alsoAccept": "team-full"`).

Notation in lesson files: `~` arc, `` ` `` k-back, `,` cedilla, `@` schwa, `=` voice, `[` bracket in front of this letter,
`#` box, `|` syllable boundary (see `docs/lesson-schema.md`).
